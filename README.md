# 再平衡台账 · 学生模式

> 在线版：https://gideon887380.github.io/rebal-ledger/

## 我是谁 / 这是什么

在校生，主动月收入 1,000 元，父母月补贴 3,000 元。**不持有独立应急金**（紧急支出向父母要）。

5 万本金 + 每月 300 元定投，目标是 5 年内毕业后靠复利攒到第一个 10 万。

本仓库的 `index.html` 是一个浏览器端记账 + 偏离度仪表板，**所有数据存在你自己的 localStorage**，不上传任何服务器。

## 现金流分配

**月预算 4,000（全部纳入，不再区分主动 / 父母来源）**

```
月入                4,000
├── 吃饭            1,200   ← 午 20 + 晚 20 × 30 天
├── 交通              100   ← 压缩后
├── 日用              100
├── 心愿              350   ← 游戏 / 数码 / 服装 / 滑雪 / 交友
├── 学习              100   ← 小额自掏
├── 其他              150   ← 备用
├── 宽基定投          800   ← 进入台账（占月预算 20%）
└── 个人缓冲          100   ← 应急 / 一次性
───────────────────────────
月结余              1,100   ← 滚存 / 一次性大额
```

**月投规则**：800 是上限，**心愿支出花超就降定投**，**当月紧张降到 400–600**，不要透支。

## 再平衡规则

两条触发线任一满足即可：

1. **时间触发**：每季度末（3/31、6/30、9/30、12/31）打开台账看一眼
2. **阈值触发**：任一类别偏离目标 > 5 个百分点（台账显示红色"再平衡"）

**操作思路**：涨多的卖到货币基金，跌多的用货币基金里的现金 + 新增定投补。

**不要做的事**：

- 每天看净值（每月看一次足够）
- 全部止盈一个、重仓另一个
- 觉得自己"看准了底部"一次性买入

## 紧急情况

由于不持有独立应急金，**任何支出 > 500 元先问父母**。不要为了短期便利卖基金——学生阶段保命比复利重要。

如果某个月现金流断了（支出超过 1,000 元主动收入 + 父母补贴），**把当月 300 元定投降到 0**，不要从本金里扣。

## 毕业后调整（预计 1–3 年后）

| 阶段 | 月投 | 配置调整 |
|---|---|---|
| 工作起薪 5k–10k | 1,500 | 月投提到 1,500，加仓债基到 30% |

| 工作 5 年 15k+ | 5,000+ | 股债平衡 60/40，加入海外 / 港股 |

每年回看一次本页和台账，根据现实调整。
